## Job Description

**Senior Full-Stack Engineer**

Remote · Full-time / Long-term contract · Senior (5+ years)

**REMUNERATION:** USD 1,700 – 2,000 / month

### Core Technologies

JavaScript, Vue.js, Node.js, AWS, Lambda, DynamoDB, CloudFormation, React

*Full stack. All of the above are actively used on the platform.*

### About the Role

We are hiring an experienced Senior Full-Stack Engineer to take ownership of a live client platform as part of a planned developer handover. You will be stepping into an established, production codebase with real users — so we are looking for someone who can read unfamiliar systems quickly, ship with confidence, and keep the product moving without a long ramp-up period.

This is a hands-on role. You will own features end-to-end, from data model through to UI, and be the senior technical voice on the platform day-to-day.

### What You'll Be Doing

- Own full-stack development of the platform across frontend and backend
- Design, build, and maintain serverless services on AWS (Lambda, DynamoDB, API Gateway)
- Write and maintain infrastructure as code using CloudFormation
- Build and extend Vue.js interfaces, with some work in React
- Extend the Node.js backend and evolve DynamoDB data models
- Take over existing code confidently — reading, understanding, refactoring, and improving it
- Collaborate with product and design to scope, estimate, and deliver features
- Monitor, debug, and optimise production systems (performance, cost, reliability)

### Must-Have Experience

- **5+ years** of professional full-stack JavaScript development
- **Strong Vue.js** — able to build and maintain production applications independently
- **Node.js** for backend APIs and serverless functions
- **AWS serverless stack in production** — hands-on with **Lambda** and **DynamoDB** is essential
- **Infrastructure as Code** using **CloudFormation** (or equivalent IaC with ability to pick up CloudFormation quickly)
- **React** — working knowledge, enough to contribute to React portions of the codebase
- Solid grasp of **NoSQL data modelling** (DynamoDB single-table design is a plus)
- Comfortable inheriting an existing codebase and evolving it with minimal hand-holding
- Strong written English and asynchronous communication skills

**AWS Activate experience is a great advantage.** The team actively uses AWS Activate, so prior hands-on experience will put you ahead of other candidates. If you haven't used it before, you will be expected to ramp up on the job within your first couple of weeks.

### Nice to Have

- Prior experience on **faith-based, community, or mission-driven products**
- Experience in small, high-ownership teams where you've owned product areas end-to-end
- Familiarity with AWS observability and cost optimisation (CloudWatch, X-Ray, billing analysis)
- CI/CD experience for serverless deployments

### What We're Looking For (Beyond the Stack)

- **Senior judgement** — someone who can walk into a live project, get oriented, and start shipping without needing to be taught fundamentals
- **Clear communication** — you push back thoughtfully, document your thinking, and surface trade-offs early
- **Willingness to commit the extra time** upfront needed to fully absorb the existing platform and any unfamiliar tooling
- **Quality-first mindset** — tests, code review, and clean handovers matter
- A steady, low-drama operator — this is a handover, not a rewrite
